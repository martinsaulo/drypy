## DRYPY - Don't Repeat Yourself Python
Motor de búsqueda de código repetido para proyectos de python. Trabajo práctico para la materia `Lenguajes Formales y Autómatas` de UCSE-DAR

### Dependencias opcionales
- Para utilizar el método `Levenshtein Distance (LD)` es requerido instalar el paquete `rapidfuzz`.
- Para utilizar el método `Tree Edit Distance (TED)` es requerido instalar el paquete `apted`.
```
pip install rapidfuzz apted
```
